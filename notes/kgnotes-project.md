# 知识图谱助手项目

知识图谱助手项目是一个个人笔记问答系统。知识图谱助手项目使用 Neo4j。知识图谱助手项目使用 FastAPI。

## 目标

把零散的 Markdown 笔记自动整理成实体关系图，并在上面做向量检索与多轮追问。
知识图谱助手项目的作者是王小明。王小明就职于示例科技公司。

## 模块

知识图谱助手项目包含向量检索模块。知识图谱助手项目包含图构建模块。
图谱构建模块依赖 [[Neo4j 与向量索引]] 中的设计。向量检索模块支持混合检索。
